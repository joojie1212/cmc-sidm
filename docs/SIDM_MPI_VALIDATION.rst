SIDM 与当前 MPI 版本的集成验证
============================

2026-11-19，在独立的 cmc-sidm 工作目录构建和测试。
基线可执行文件为当日 CMC-COSMIC 的 MPI 本地输入和节点共享内存版本的副本。
原 CMC-COSMIC 目录的 227 个源码、测试和可执行文件经 SHA-256 对照未改变。

验证结果
--------

* 散射核：200000 次抽样检查弹性动能/局部动量守恒、各向同性，
  以及零相对速度和奇偶球壳的抽样权重归一化。
* ``tests/test_dm_sidm.py``：28 个运行场景通过，包括预期失败的输入校验。
  覆盖纯引力 DM、SIDM、混合模型、单 DM、奇数粒子球壳、恒星演化隔离、
  双星/强相互作用隔离、非法输入、重启、截面线性、MPI 1/2/4 进程、
  跨进程 DM 配对和共享/复制存储模式的数值一致性。
* 事件测试：观察到 74 次散射，期望为 80.5484503293817 次；
  SIDM 步骤最大相对动能变化为 2.2740854077540713e-16。
  该值仅测量弹性散射步骤，不是整个轨道演化的总能量误差。
* ``tests/mpi_local_io/regression.py``：36 个基线/新版本运行场景通过。
  对照包括单星、原初双星、真实遭遇、恒星演化、快照、中央质量、
  硬/软重启、不同 MPI 进程数、非均匀双星分配，以及损坏 checkpoint 的拒绝。
  这里没有 DM，检验原恒星/BH 行为和 MPI 输入/重启接口未被 SIDM 改变。
* ``tests/node_shared/run_storage_tests.sh``：复制、单节点共享及两个模拟节点组通过。
  4 个进程、2000003 个对象的数组测试中，进程 PSS 合计分别为
  208819、68413、115365 KiB。这是数组测试，不是生产模拟总内存的保证。
* 新 SIDM C 源码通过 ``-Wall -Wextra -Werror`` 语法检查。

适用边界
--------

这些测试确认实现与 MPI 层的基本正确性，不代替物理收敛验证。
真实系统应检查 DM 粒子数、径向球壳大小、散射概率上限和轨道平均假设。
SIDM 散射仍在根进程执行，应另外评估超大模型的通信及根进程内存。
